## The problem

A useful assistant has to remember appointments, health, money and family. That is exactly the data you should not paste into a cloud model. <Src l="18-19" /> Any team that sends customer or staff data to a hosted model faces the same question: what left, and who can prove it?

## What I built

- Memory with receipts: each memory records who said it, where it came from, when, and every correction. Answers cite memories. <Src l="22-23" />
- A guard that classes memories as public, personal or private, and replaces private ones with placeholders before any call leaves the device. <Src l="24-26" />
- Late binding: <Mark l="7-8">the cloud model never sees a private fact</Mark>. It answers with a placeholder, and Confidant fills in the real value locally.
- A receipt for every outbound call: provider, model, tokens, memories sent and withheld, and a SHA-256 of the exact messages. <Src l="27-29" />
- An MCP server with 6 tools that never hands a client a private memory's text. <Src l="116-118" />

## How it is verified

- An offline test suite with all HTTP mocked. <Src l="241" />
- Adversarial leak test: reviewers that did not write the guard wrote the attack rounds, and NVIDIA Nemotron 3 Ultra wrote round 9. Every finding became a test. All 199 attack messages now run in the suite and none leaks, per README. <Src l="153-180" />
- A "Prove it" check rebuilds the last turn with private appointments moved and compares SHA-256 hashes. They are identical for every demo question. <Src l="32-36" />
- The README calls this a regression result, not an estimate: no new attack round has been written against this version yet. <Src l="180-182" />

## What this means for your project

- If an assistant touches HR, health or finance data, a guard plus late binding keeps the values out of the hosted model's context. That is an **Agent or MCP build**.
- Receipts turn "what did we send to the vendor today?" into a table, not a guess. <Src l="30" />
- A **Microsoft 365 and Entra security review** covers the other half: what the connector itself can reach.
