# yannabadie.github.io

Source of https://yannabadie.github.io/, the portfolio of Yann Abadie, Senior AI & Cloud Security Architect.

Static site: Astro, Tailwind CSS v4, two small vanilla scripts. No trackers, no cookies.

```sh
npm ci
npm run dev      # local server
npm run verify   # build, type check, byte budgets, HTML validity
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
